Restaurant Review Sentiment Analysis

Project Overview

This project focuses on analyzing restaurant customer reviews using Natural Language Processing (NLP) and Machine Learning techniques. It processes text reviews and predicts sentiment using a Naive Bayes classification algorithm.

Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib

Project Workflow

1. Import required Python libraries.
2. Load the restaurant reviews dataset.
3. Clean and preprocess the text data.
4. Remove stopwords and perform stemming.
5. Convert text into numerical features using CountVectorizer (Bag of Words).
6. Split the dataset into training and testing sets.
7. Train the model using Gaussian Naive Bayes.
8. Predict sentiment on test data.

Machine Learning Algorithm

- Gaussian Naive Bayes

Project Files

- "Restaurant_Review_Analysis.ipynb" – Jupyter Notebook containing the implementation.

Learning Outcomes

- Understanding Natural Language Processing.
- Text preprocessing and feature extraction.
- Implementing a machine learning classification model.
- Analyzing customer review data.
